# caps_5001_fall_2026

## Setup

### 1. Create and activate a virtual environment

```bash
python -m venv venv
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

**Windows:**
```bash
venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the project

```bash
python <your_script>.py
```
